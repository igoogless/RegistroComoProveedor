Qué hace este proyecto

Automatiza la preparación de registros como proveedor a partir de una solicitud y un repositorio maestro de datos y soportes.

Flujo funcional

  • Lee el caso seleccionado, sus campos y los soportes que el cliente exige.
  • Relaciona cada campo con el maestro, indicando valor, ruta, faltantes o confirmaciones necesarias.
  • Genera un formulario XLSX o PDF; para portales crea una lista de valores para copiar.
  • Arma un paquete con formulario, soportes, checklist de vigencias y borrador de correo.
  • Solo simula el envío después de una confirmación explícita; nunca firma ni envía correos reales.

Cómo usarlo

Escribe Procesa el caso "ec-corp-andina". Revisa las herramientas visibles, el estado del paquete y los soportes pendientes.
